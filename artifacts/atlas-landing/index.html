Coding-agent harness

A coding agent you can read all the way down.

Atlas runs the agent loop itself: raw LLM calls through the Vercel AI SDK, and its own code deciding what the model sees, which tools it may call, when a human is asked, and what happens on rewind.

What it does

  1. 01

    Owns the loop

    Context assembly, tool selection, permission checks and rewind are harness code, not a vendor SDK's defaults. Nothing important sits behind an API you cannot open.

  2. 02

    Model-agnostic

    Claude and Codex credentials are one provider among several. You bring the keys; swapping the model does not change how sessions think.

  3. 03

    Long-lived sessions

    Agents run in cloud sandboxes and survive disconnects. The web app, the Mac app and the terminal attach to the same session over different transports.

  4. 04

    Ships what it builds

    Static sites publish straight from the repo as artifacts, and dev servers come up as previews — this page is one of them.

Small, public, in progress

Atlas is a public repo with one daily user, under active development. No customer logos, no case studies, no benchmarks — the honest claim is that the whole harness is readable, and that it works well for the person building it.
