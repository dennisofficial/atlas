## A2. `scripts/check-package-readmes.ts`

- Discovery: `PACKAGE_MANIFEST_GLOB = '{packages,plugins}/*/package.json'` (`scripts/check-package-readmes.ts:3`),
  scanned from the repo root at `:22-26`, plus `commands/package.json` (`:4`). It reads only what exists, so
  **deleting `packages/harness`, `packages/agent-v1`, `apps/serve` or `packages/wire` cannot fail it** — the
  deleted directory simply stops being scanned. Nothing enumerates the workspace list from the root
  `package.json` (`package.json:6-12`), and `apps/*` is never scanned at all.
- Exemption: `README_EXEMPT = ['packages/agent-v1', 'packages/harness']` (`scripts/package-readmes/audit.ts:7`),
  documented at `docs/package-readmes.md:19-20`. Those two packages have **no `README.md` today**; after deletion
  the entries are dead strings that silently exempt nothing. Remove both, and remove the sentence at
  `docs/package-readmes.md:19-20`.
- What would fail instead: any package that **survives** while its README disappears, or a public-surface change
  (an `exports` subpath) whose README does not name it in backticks (`audit.ts:21-31`). Also
  `bun scripts/check-package-readmes.ts` prints `clean (<n> packages)`, so the count in that line is the only
  signal that a deletion happened.

## B(c) Does v2 reference v1 rows?

No.
- FKs whose **source is in a non-`public` schema and target is a `public` table: 0 rows** (`pg_constraint`
  query in B(d)). The `v2` schema declares no cross-schema foreign key at all.
- Id overlap: `public."Thread"` ∩ `v2."V2Thread"` = **0**; `public."Session"` ∩ `v2."V2Session"` = **0**;
  `public."CloudSandbox".sandboxId` ∩ `v2."V2Session".sandboxInstanceId` = **0**.
- Consequence: the v1 rows can be dropped without a data migration, and without touching v2 read paths. The only
  v1 rows v2 code reads at runtime are read through the v1 lane in `apps/api` (the `orm.public.Thread`
  / `CloudSandbox` / `Event` / `SandboxBootStep` accessors), so the code lane must go first.

## B(d) Foreign keys pointing at `Thread` / `Event`

| Constraint                    | From                   | To       | On delete              |
| ----------------------------- | ---------------------- | -------- | ---------------------- |
| `Event_threadId_fkey`         | `public.Event`         | `Thread` | CASCADE                |
| `Turn_threadId_fkey`          | `public.Turn`          | `Thread` | CASCADE                |
| `ThreadRead_threadId_fkey`    | `public.ThreadRead`    | `Thread` | CASCADE                |
| `ContextFile_threadId_fkey`   | `public.ContextFile`   | `Thread` | CASCADE                |
| `ComposerDraft_threadId_fkey` | `public.ComposerDraft` | `Thread` | CASCADE                |
| `Session_mainThreadId_fkey`   | `public.Session`       | `Thread` | **NO ACTION** (blocks) |
| `Thread_parentThreadId_fkey`  | `public.Thread`        | `Thread` | SET NULL               |
| `Thread_spawnerThreadId_fkey` | `public.Thread`        | `Thread` | SET NULL               |

Nothing references `Event` except its own `Thread` (`event.prisma:17`); there is no FK into `Event` from any other
table. So `DELETE FROM public."Thread"` cascades the whole thread family, **but `Session.mainThreadId` is
`NO ACTION` and will refuse** until the `Session` rows are deleted first or that FK is dropped. `Session` is in
turn referenced by `CloudSandbox.sessionId` (`ON DELETE CASCADE`, `cloud-sandbox.prisma:32`). A safe order is
`CloudSandbox` → `Session` → `Thread` (cascades Event/Turn/ThreadRead/ContextFile/ComposerDraft) →
`SandboxBootStep`, `PreviewTunnel`, `PreviewRoute`, `LocalPodLease`.

## Queries used (rerun if needed)

```sql
-- sizes
select c.relname, pg_size_pretty(pg_total_relation_size(c.oid)), pg_total_relation_size(c.oid)
from pg_class c join pg_namespace n on n.oid=c.relnamespace
where n.nspname='public' and c.relkind='r' order by 3 desc;

-- exact counts
select count(*) from public."Event";   -- and Thread, Session, Turn, ThreadRead, ContextFile, CloudSandbox, ...

-- sandbox state and serve version
select state, count(*), max("lastActivityAt") from public."CloudSandbox" group by 1;
select "runningServeVersion", count(*), max("lastActivityAt") from public."CloudSandbox" group by 1;

-- v1 activity windows
select count(distinct "threadId") filter (where at > now() - interval '7 days'),
       count(distinct "threadId") filter (where at > now() - interval '30 days'),
       max(at) from public."Event";

-- no v2 -> public FK
select src_ns.nspname||'.'||src.relname, tgt_ns.nspname||'.'||tgt.relname
from pg_constraint con
join pg_class src on src.oid=con.conrelid join pg_namespace src_ns on src_ns.oid=src.relnamespace
join pg_class tgt on tgt.oid=con.confrelid join pg_namespace tgt_ns on tgt_ns.oid=tgt.relnamespace
where con.contype='f' and src_ns.nspname<>'public' and tgt_ns.nspname='public';

-- FKs into Thread/Event
select con.conname, src_ns.nspname||'.'||src.relname, pg_get_constraintdef(con.oid)
from pg_constraint con
join pg_class src on src.oid=con.conrelid join pg_namespace src_ns on src_ns.oid=src.relnamespace
join pg_class tgt on tgt.oid=con.confrelid join pg_namespace tgt_ns on tgt_ns.oid=tgt.relnamespace
where con.contype='f' and tgt_ns.nspname='public' and tgt.relname in ('Thread','Event');
```
