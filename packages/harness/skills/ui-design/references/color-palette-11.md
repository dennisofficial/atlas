# Color palette 11: pink-vivid

## Apply this

- If a coherent pink-vivid color system fits the task, use palette 11 as a complete candidate.
- Map these source roles to existing semantic tokens, not new component literals: Primary: pink-vivid; Neutrals: cool-grey; Supporting: purple-vivid, cyan-vivid, red-vivid, yellow-vivid.
