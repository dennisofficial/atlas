# Further application font specimens

## Apply this

- If the first application candidates do not fit, compare these additional application specimens.
- Test the candidates in dense labels, controls, numbers, and mixed-length data before changing the family token.
- Use the images for raster-only specimen names and details; verify current licensing, glyph coverage, and actual weight files.

## Source

Source: `Font Recommendations v1.0.1.pdf`, version 1.0.1, PDF pages 56–69.
Apply this is new guidance; the source blocks below preserve the supplied pypdf extraction verbatim.
Page images preserve the original visual content, including text absent from extraction.
