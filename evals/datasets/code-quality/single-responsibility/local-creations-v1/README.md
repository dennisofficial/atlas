# local-creations-v1

34 sanitized scopes from successful historical Atlas `write` creations. Complete before is null by the contemporaneous write result; complete after comes from the matching input whose UTF-8 byte count the result verifies. Public Atlas source paths only.

The offline drafter and separate blind reviewer saw no Jev output. Their expected judgments agreed on every accepted case; review identities, rationale, uncertainty and input/rubric hashes are in `judgments.jsonl` and `review-audit.jsonl`. The reviewer model identity is unknown because Atlas does not expose that to sub-agents. This is machine-reviewed evidence, not human verification.

All cases are one repository group and all judged benign: 33 `unchanged` and one `not_applicable`, with no concern, evidence or warranted notification positives. It is a development pilot against unsolicited-advice false positives, not a recall or holdout corpus. `eval:efficacy` prints the frozen Weka 0-R mode yardstick; matching it is not model gain.

Real logs were read only from explicitly named session directories. Raw provenance and the strict historical importer's local verification are retained privately outside Git. No raw transcript or secret is included.
