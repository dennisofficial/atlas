# Application font specimens and weight ranges

## Apply this

- If interface text is inconsistent, compare the first application specimens using the same realistic screen content.
- Map the selected family and genuine weights to label, body, heading, and control tokens.
- Open the page images: many specimen details are raster-only; verify small-size legibility, licensing, and fallback metrics.
