# Color palette reference provenance

## Apply this

- If choosing a color system, inspect one complete palette instead of mixing isolated swatches.
- Keep existing semantic token names and map chosen shades to their actual interface roles.
- Verify contrast in real components; source palette availability does not guarantee accessible pairings.
