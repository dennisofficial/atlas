# Color palette 19: indigo, orange-vivid

## Apply this

- If a coherent indigo, orange-vivid color system fits the task, use palette 19 as a complete candidate.
- Map these source roles to existing semantic tokens, not new component literals: Primary: indigo, orange-vivid; Neutrals: cool-grey; Supporting: magenta-vivid, red-vivid, yellow-vivid, green-vivid.
- Keep palette-specific values intact; do not substitute matching names from swatches.json. Test text, surface, focus, hover, and status contrast, and pair status colors with another cue.
