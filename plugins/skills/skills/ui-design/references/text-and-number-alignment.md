# Align content for reading and comparison

## Apply this

- If content is hard to scan, choose alignment for the kind of information shown.
- Left-align long prose and right-align comparable numbers; handle justified text with care.
- Use centering only for short content and verify wrapping, hyphenation, and numeric columns.

```text
Align with readability in mind
In general, text should be aligned to match the direction of the language it’s
written in. For English (and most other languages), that means that the vast
majority of text should be left-aligned.
Other alignment options do have their place though, you just need to use
them effectively.
Don’t center long form text
Center-alignment can look great for headlines or short, independent blocks
of text.

```

```text
Right-align numbers
If you’re designing a table that includes numbers, right-align them.
```
